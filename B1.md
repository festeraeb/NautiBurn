## Trace

Header and rows: `b1/trace.tsv`.

Prompt: `Write a Python function named add that returns the sum of two integers.`

Context 512. Batch 64. `-ngl 99`. Flash attention off. Seed 1.

llama.cpp token ids and gigatoken ids for that prompt are the same 14 ids: `10639 247 13814 1159 4907 823 326 6548 253 2020 273 767 20935 15`.

Rows come from the `ffn_moe_topk` tensor (`i32`, `ne0=8`). Prefill layers 0–14 have all 14 prompt tokens. Prefill layer 15's tensor was `ne0=8 ne1=1`, so only prompt token 0 is recorded there. Decode is one greedy token, id 187, and that tensor is `ne1=1` on all 16 layers. Those shapes are what the graph callback returned. Missing layer-15 prefill positions were not filled in.
