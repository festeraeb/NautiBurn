## Message / protocol design

**Envelope (Warp v1):** Every message crossing pillar boundaries uses a common envelope:

```json
{
  "v": 1,
  "id": "uuid",
  "ts": "iso8601",
  "type": "task.dispatch | task.ack | task.result | chat.msg | node.health | os.optimize.plan | os.optimize.apply | escalation.request | helpdesk.ticket",
  "from": {"pillar": "buzz", "node": "t440", "actor": "human:webui" },
  "to":   {"pillar": "forge", "node": "*", actor": "agent:forge"},
  "topic": "dispatch.board",
  "corr": "uuid-of-parent",
  "sec": {"tok": "...", "scope": "buzz.write"},
  "body": { ... },
  "via": ["buzz:8088"],
  "ttl": 300
}
```

Key semantics:
- `type` — verb.noun naming.
- `from/to` — pillar + node + actor.
- `corr` — correlation id chains results back to origin.
- `via`
