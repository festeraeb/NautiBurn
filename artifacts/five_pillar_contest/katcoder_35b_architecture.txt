## Buzz API Specification

### Endpoints:
- `POST /api/buzz/dispatch` - Dispatch task to Forge
- `POST /api/buzz/acknowledge` - Agent acknowledges task
- `POST /api/buzz/progress` - Report progress
- `POST /api/buzz/complete` - Mark task complete
- `POST /api/buzz/escalate` - Escalate issue
- `GET /api/buzz/tasks` - List all tasks
- `GET /api/buzz/tasks/{id}` - Get task details
- `GET /api/buzz/inbox` - Human operator inbox
- `POST /api/buzz/inbox/reply` - Reply to operator
- `GET /api/buzz/feed` - SSE live chat feed
- `GET /api/buzz/nodes` - Node health
- `POST /api/buzz/node/{id}/optimize` - Trigger OS optimizer
