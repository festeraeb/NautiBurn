## Types

`ExpertId` is a `u16` slab index. `SpecialistId` is a model-id string. `SpecialistId` does not implement `ExpertSlot`. A job record has no expert-id field.

Job fields: mission id, task class (`code`, `json`, `prose`, `tool`), language, token estimate, tools, inputs, outputs, lease (`id`, `expires_at_unix_s`), device affinity.

Log envelope on both kinds: timestamp, machine, device uuid, backend, dtype, plus `kind`.

Expert payload: phase, layer, expert ids, token id, arch, quant, predicted ids, hit, dispatch (`gpu_resident`, `cpu_miss`, `prefetch_hit`).

Specialist payload: mission id, role, model id, quant, tools required, tools-ready timestamp, grade, stance, dispatch (`preloaded`, `polisher_miss`).
